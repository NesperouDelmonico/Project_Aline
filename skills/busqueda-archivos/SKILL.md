name: busqueda-archivos
description: Encontrar archivos o carpetas cuando el usuario solo recuerda parte del nombre o dónde estaban.
---
Cómo buscar archivos:

1. Las rutas son relativas a la carpeta personal: Documentos, Descargas, Escritorio, Imágenes, etc.
2. Si el usuario dice dónde está ("en Descargas"), pásalo en 'carpeta' para buscar más rápido.
3. En 'consulta' usa solo las palabras clave del nombre, sin artículos: "informe operaciones", no "el informe de la clase de operaciones".
4. Si sabe el tipo de archivo ("el Word", "el PDF"), usa 'extension' (docx, pdf...).
5. Si no hay resultados, prueba con menos palabras o con sinónimos antes de rendirte.
6. Si hay varios resultados, di los nombres de los dos o tres primeros y pregunta cuál quiere. No leas las rutas completas: di el nombre del archivo y la carpeta donde está.
7. Para ver qué hay en una carpeta, usa listar_carpeta.
