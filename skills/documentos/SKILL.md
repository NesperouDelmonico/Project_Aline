---
name: documentos
description: Crear, resumir o editar documentos (docx, txt, md) o leer PDF.
---
Cómo trabajar con documentos:

1. Si no tienes la ruta exacta, usa buscar_archivos. Si hay varias coincidencias, pregunta cuál.
2. Nunca inventes el contenido de un archivo: léelo con leer_archivo antes de resumirlo o editarlo.
3. Si el archivo tiene varias partes y la tarea lo necesita, lee las siguientes partes.
4. Para cambios puntuales usa editar_archivo. El texto de 'buscar' debe copiarse exacto de lo que leíste; cambia frases cortas, no párrafos enteros.
5. Para añadir contenido al final usa agregar_al_archivo.
6. Para documentos nuevos usa crear_archivo. Si el usuario no da nombre, elige uno corto y descriptivo con guiones bajos, por ejemplo Documentos/resumen_reunion.docx.
7. Al escribir contenido: '# ' para el título, '## ' para secciones y '- ' para viñetas. Escribe en el idioma del usuario.
8. Los PDF solo se pueden leer. Si piden modificar uno, ofrece crear un docx con los cambios.
9. Al terminar, di en una o dos frases qué hiciste y el nombre del archivo. No leas el contenido completo en voz alta.
